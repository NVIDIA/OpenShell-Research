# OpenShell Event Exporter v0.0.4

Experimental research example, provided as-is. Use at your own risk. No production
readiness or support commitment is implied. User-built images are unsigned unless their builder signs them.

This release includes bounded policy reconciliation, file qualification tooling,
and aligned Docker/Podman/Helm authentication and persistent state. Source auth
supports bearer, mTLS, or both. Standalone, edge, central, and custom profiles
remain available; the envelope stays `urn:openshell:event-envelope:1`.

This branch uses source releases: [build the exporter and optional proxy](../../deploy/README.md)
for Linux AMD64 or ARM64. Use local images for development and your own registry
for shared clusters. No project-published images are required.

On upgrade, preserve checkpoints, every queue, reconciliation state, and recovery
output. Grant the runtime user access to those paths. mTLS-only sources need no
bearer file; rootless Podman requires cgroup v2 delegation.

See [compatibility](../../docs/compatibility.md) for pins and unverified paths.
Real source coverage, file lifecycle reconciliation, cluster failure/scaling,
external destinations, capacity, and privacy/security qualification remain
incomplete. Historical CI or demo results do not qualify this cleanup branch.
