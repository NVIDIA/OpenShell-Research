Install Relay

Relay requires Linux and Python 3.12. Download relay.tar.gz and verify that the
published SHA-256 checksum matches the archive before continuing.

Extract the archive. Run `./install.sh`. Copy relay.toml to /etc/relay/relay.toml
and set `listen_address` to the service address. Start Relay with
`systemctl --user start relay`.

If the command fails, rerun it. The installation is now complete.
